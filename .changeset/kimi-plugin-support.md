Add native **Kimi Code** plugin support alongside the existing Claude Code plugin. The repo now ships `.kimi-plugin/plugin.json` (with the same promoted skill set) and `.kimi-plugin/marketplace.json`, so Kimi users can install directly from GitHub:

```
/plugins install https://github.com/GoooIce/skills
```

Or add the custom marketplace via the raw `.kimi-plugin/marketplace.json` URL.
